# Humanverse v3

Nowa strona Humanverse: ekosystem rozwiązań AI dla marketingu (Marketing Solutions, Studio, Jeden.ai, AlterCast) z klasycznym logotypem i interaktywną siatką w tle.

- [`docs/PLAN.md`](docs/PLAN.md): plan strony, architektura, sekcje, technologia, etapy.
- [`prototype/index.html`](prototype/index.html): klikalny koncept (jeden plik, bez zależności). Otwórz w przeglądarce, poruszaj kursorem i przewijaj.
- [`brand/`](brand/): robocze pliki logo (znak ┐H i logotyp) do czasu otrzymania plików źródłowych.
